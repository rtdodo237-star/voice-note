# 녹음 노트 → 말씀노트 자동 연결 가이드

> 작성일: 2026-11-08 · 대상: Christine (rtdodo237@gmail.com 구글 계정)
> 결과: 녹음 노트 앱으로 녹음 → 자동 받아쓰기(화자 구분) → Claude가 분류별 지침대로 정리 → 말씀노트에 등록
> 처음 한 번 설정 약 15분 (PC 권장)

---

## 1. 전체 흐름

```
[녹음 노트 앱]  저장하면 바로 전송
      ↓
[구글 드라이브]  내 드라이브 > 녹음노트 > 1_음성
      ↓  (Apps Script가 5분마다 확인)
[VITO 받아쓰기]  상담·회의는 화자 구분, 말씀은 성경 66권 · 상담은 보험 용어 인식 강화
      ↓
[구글 드라이브]  녹음노트 > 2_녹취  (녹취록 .md)
      ↓  (Claude 예약 작업 '말씀노트 자동 등록'이 매시 18분 확인)
[말씀노트]  분류(말씀·회의·상담·강의)별 지침대로 AI 정리 + 녹취록 탭
```

| 단계 | 누가 | 걸리는 시간 |
|---|---|---|
| 드라이브 전송 | 녹음 노트 앱 | 녹음 저장 직후 (1시간 녹음 ≈ 22MB) |
| 받아쓰기 | Apps Script + VITO | 5분 안에 시작, 녹음 길이에 따라 수 분 |
| 말씀노트 등록 | Claude 예약 작업 | 최대 1시간 |

## 3. VITO 키 받기

1. **developers.rtzr.ai** 접속 → 회원가입 · 로그인

## 4. Apps Script 연결 서버 만들기

### 4-1. 프로젝트 만들기
1. **script.google.com** → rtdodo237@gmail.com 계정으로 로그인 → **새 프로젝트**
2. 왼쪽 위 '제목 없는 프로젝트' → 이름을 `녹음노트 연결` 로 변경

### 4-2. 코드 붙여넣기
1. 저장소의 **apps-script/Code.gs** 내용을 전부 복사
   - https://github.com/rtdodo237-star/voice-note/blob/main/apps-script/Code.gs → 오른쪽 위 복사 버튼
2. 편집기의 `Code.gs` 내용을 모두 지우고 붙여넣기
3. 맨 위 두 줄에 VITO 키 넣기
   ```js
   const VITO_CLIENT_ID = '복사한 Client ID';
   const VITO_CLIENT_SECRET = '복사한 Client Secret';
   ```

### 4-3. 권한 설정 파일 붙여넣기
1. 왼쪽 **⚙ 프로젝트 설정** → **"편집기에서 'appsscript.json' 매니페스트 파일 표시"** 체크
2. 왼쪽 **< > 편집기**로 돌아와 `appsscript.json` 열기
3. 저장소의 **apps-script/appsscript.json** 내용으로 전부 바꾸기 → 저장(⌘S / Ctrl+S)

### 4-4. 처음 실행 (setup)
1. 위쪽 함수 선택 상자에서 **setup** 선택 → **▶ 실행**
2. 권한 창: **권한 검토** → 계정 선택 → "Google에서 확인하지 않은 앱" 화면이 나오면 **고급 → 녹음노트 연결(으)로 이동** → **허용**
   - 내가 만든 스크립트라 나오는 정상 안내예요. 권한은 '이 연결이 만든 파일만'이라 다른 드라이브 파일은 건드리지 않아요.
3. 아래 **실행 로그**에서 확인
   - `연결 키: …` ← **복사해 두기**
   - `VITO 연결: 정상` ← '키 확인 필요'면 4-2의 키를 다시 확인 후 setup 재실행
4. 내 드라이브에 `녹음노트` 폴더(안에 `1_음성`, `2_녹취`)가 생겼는지 확인

### 4-5. 웹 앱으로 배포
1. 오른쪽 위 **배포 → 새 배포**
2. 톱니(유형 선택) → **웹 앱**
3. 설정
   - 설명: `녹음노트 연결`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
4. **배포** → **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)

> 코드를 나중에 고치면 **배포 → 배포 관리 → ✏ 수정 → 버전: 새 버전 → 배포** 해야 반영돼요. (URL은 그대로)

## 5. 녹음 노트 앱에 연결 (기기마다 한 번)

1. 녹음 노트 앱 열기 → 오른쪽 위 **말씀노트 연결**
2. **연결 주소**: 4-5의 웹 앱 URL
3. **연결 키**: 4-4의 연결 키
4. **연결 확인** → "연결됐어요 … VITO 받아쓰기 준비 완료" 확인 → **저장**
5. 홈에 초록 점 **말씀노트 연결됨** 표시

맥 · 아이폰 · 갤럭시 각각 한 번씩 넣어 주세요. (주소와 키는 그 기기에만 저장)

**갤럭시 설치 앱(APK)** 도 똑같이 홈 오른쪽 위 **말씀노트 연결**에 같은 주소·키를 넣으면 돼요. 화면을 끈 채 녹음한 것도 저장하면 바로 드라이브로 가고, 인터넷이 끊겼던 녹음은 앱을 다시 열 때 자동으로 보내요.

## 6. 첫 시험

1. 강의 모드로 **1분 정도** 녹음 → 저장
2. 상세 화면 **말씀노트 연결**
   - 드라이브 전송 ✅ → 받아쓰기 (5분 안에 시작) → 완료 ✅
3. 드라이브 `녹음노트/2_녹취` 에 `.md` 파일 생성 확인
4. 매시 18분 이후 **말씀노트**에 '강의' 분류 · `녹음노트` 태그로 노트 등록
   - 요약 탭: 강의 지침대로 정리 · 녹취록 탭: 받아쓴 전문

## 7. 분류별 동작

| 앱 모드 | 말씀노트 분류 | 화자 구분 | 인식 강화 단어 | 정리 지침 |
|---|---|---|---|---|
| 상담 | 상담 | 2명 | 보험 용어 · 손보사 이름 | 고객 상황 · 니즈 · 안내 내용 · 약속/후속조치 · 다음 확인 |
| 회의 | 회의 | 자동 판단 | — | 할 일 · 결정 사항 · 논의 요약 · 다음 일정 |
| 강의 | 강의 | 1명 | — | 3줄 요약 · 챕터별 정리 · 핵심 개념 · 기억할 것 · 적용점 |

- 상담 정리에서는 주민번호 · 카드번호 · 계좌번호를 **[가림]** 으로 바꿔 적어요.

## 8. 문제 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| 연결 확인: "연결 키가 맞지 않아요" | 키 오타 · resetKey 실행함 | Apps Script 실행 로그의 키 다시 복사 |
| 연결 확인: "연결 주소가 맞지 않아요" | /exec 가 아닌 주소 | 4-5의 **웹 앱 URL** 사용 (편집기 주소 X) |
| "VITO 키가 아직 없어요" | 4-2 키 미입력 | 키 입력 → setup 재실행 → **새 버전으로 재배포** |
| 전송 실패 반복 | 인터넷 · 권한 만료 | 상세 화면 **다시 보내기** (앱을 열 때도 자동 재시도) |
| 받아쓰기 실패: 지원하지 않는 형식 | 오래된 브라우저의 webm 녹음 | 아이폰 · 최신 크롬으로 녹음 |
| 받아쓰기 실패: 파일이 너무 커요 | 48MB 초과 (약 2시간 넘는 녹음) | 1시간 단위로 끊어 녹음 |
| 받아쓰기 완료인데 말씀노트에 없음 | 예약 작업 대기 (매시 18분) | 최대 1시간 기다리기 · Claude에게 "새 녹음 가져와" 요청 가능 |
| 5분이 지나도 '받아쓰기 대기' | 트리거 미설치 | Apps Script 왼쪽 ⏰ 트리거에 processQueue 있는지 확인 → 없으면 setup 재실행 |

## 9. 보안 · 개인정보

- 녹음 원본은 **각 기기 + 내 구글 드라이브**에만 저장돼요. 앱 코드 저장소(GitHub)에는 녹음이 올라가지 않아요.
- Apps Script 권한은 **drive.file** (이 연결이 만든 파일만). 다른 드라이브 파일은 읽지도 고치지도 않아요.
- 연결 키를 아는 사람만 업로드 권한을 받을 수 있어요. 키가 새어 나갔다면 Apps Script에서 **resetKey** 실행 → 기기마다 새 키 입력.
- VITO는 받아쓴 결과를 3일 동안만 보관 후 삭제해요.
- 상담 녹음은 고객 개인정보예요. 녹음 전 고지(앱이 시작할 때 확인), 드라이브 보관 기간은 내규로 정해 두세요.
