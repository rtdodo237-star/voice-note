# 녹음 노트 — Phase 1-a: 모드 선택 + 녹음 화면

> 작성일: 2026-11-08 · 스택: Expo SDK 58 + React Native + TypeScript
> 범위: 4개 모드(상담·회의·강의·말씀) 선택 → 녹음/일시정지/종료 → 제목 저장 → 목록·재생 · **백그라운드 녹음(화면 꺼도 계속)**
> 다음 단계: STT 엔진 연결(텍스트 변환) → 모드별 md 생성

## 1. 이번 단계에서 되는 것

| 기능 | 설명 |
|---|---|
| 모드 선택 | 상담 🤝 / 회의 👥 / 강의 🎓 / 말씀 📖 — 마지막 선택 모드 기억 |
| 녹음 동의 확인 | 상담·회의·강의는 시작 전 "녹음 고지/허락" 확인 팝업 |
| 녹음 | 시작·일시정지·재개·종료, 실시간 타이머, 음량 파형 |
| 백그라운드 녹음 | 화면을 끄거나 다른 앱을 써도 녹음 계속 (개발 빌드 필요, §4) |
| 끊김 복구 | 전화·알람으로 녹음이 끊기면 앱 복귀 시 자동으로 일시정지 표시 → ▶로 이어서 녹음 |
| 저장 | 종료 후 제목 입력 (상담=고객명, 말씀=본문 안내) |
| 목록 | 전체/모드별 필터, 날짜·길이 표시 |
| 재생 | 재생/일시정지, ±15초, 배속(1~2x), 진행바 |
| 삭제 | 확인 후 목록에서 삭제 |
| 변환 버튼 | 자리만 잡아둠 (다음 단계에서 STT 연결) |

녹음 파일은 **앱 문서 폴더**에 저장돼서 폰 저장공간이 부족해도 시스템이 임의로 지우지 않습니다. 모노·96kbps라 1시간 녹음 ≈ 약 43MB.

## 2. 파일 구조

```
voice-note/
├── App.tsx                 # 진입점: 권한·오디오 설정·화면 전환
├── app.json                # 앱 이름, 마이크 권한 문구, 백그라운드 녹음 설정
├── eas.json                # EAS 클라우드 빌드 설정 (설치파일 만들기)
└── src/
    ├── modes.ts            # ★ 4개 모드 프리셋 (화자분리·키워드·요약항목·RAG 컬렉션)
    ├── storage.ts          # 녹음 목록 저장(기기 내부)·시간 표시 도우미
    └── screens/
        ├── HomeScreen.tsx   # 모드 선택 + 녹음 목록
        ├── RecordScreen.tsx # 녹음 화면
        └── DetailScreen.tsx # 재생·상세·삭제
```

모드를 추가하거나 키워드를 바꾸고 싶으면 **`src/modes.ts`만 수정**하면 됩니다.

## 3. 설치·실행 (처음 한 번)

PC에 Node.js(LTS)가 설치돼 있어야 합니다.

```bash
# 1) 빈 Expo 프로젝트 생성
npx create-expo-app@latest voice-note --template blank-typescript
cd voice-note

# 2) 필요한 라이브러리 설치
npx expo install expo-audio expo-keep-awake @react-native-async-storage/async-storage react-native-safe-area-context

# 3) 이 폴더의 App.tsx, app.json, eas.json, src/ 폴더를 덮어쓰기
```

## 4. 백그라운드 녹음 — 내 폰에 설치하기

백그라운드 녹음은 마이크를 "계속 쓰는 앱"으로 OS에 등록해야 해서 **Expo Go로는 안 되고, 내 앱 설치파일을 직접 만들어야** 합니다. Expo의 클라우드 빌드(EAS)를 쓰면 PC에 안드로이드 스튜디오 없이 만들 수 있어요.

### 4.1 준비 (처음 한 번)

```bash
# EAS 도구 설치 + Expo 계정 로그인 (expo.dev에서 무료 가입)
npm install -g eas-cli
eas login

# 개발용 앱 라이브러리 설치
npx expo install expo-dev-client

# 프로젝트를 Expo 계정에 연결
eas init
```

### 4.2 안드로이드 (권장 — 무료, 바로 설치)

```bash
eas build -p android --profile development
```

- 10~20분 뒤 터미널과 expo.dev에 **다운로드 링크/QR**이 나옴
- 폰으로 링크 열기 → APK 설치 ("출처를 알 수 없는 앱" 허용)
- PC에서 `npx expo start --dev-client` 실행 → 설치한 앱에서 QR 스캔
- 이후 코드 수정은 다시 빌드할 필요 없이 바로 반영됨 (라이브러리 추가 시에만 재빌드)

PC 연결 없이 단독으로 쓰는 설치파일(직원 배포용)이 필요하면: `eas build -p android --profile preview`

### 4.3 아이폰

- **Apple 개발자 계정(연 $99)이 필요**합니다.
- `eas device:create` 로 내 아이폰 등록 → `eas build -p ios --profile development`
- 사내 배포·스토어 배포도 같은 계정으로 이어서 가능

### 4.4 동작 방식

| 상황 | 안드로이드 | 아이폰 |
|---|---|---|
| 화면 끄기 / 잠금 | 녹음 계속 | 녹음 계속 |
| 다른 앱 사용 | 녹음 계속 | 녹음 계속 |
| 녹음 중 표시 | 알림창에 "녹음 중" 고정 알림 + 정지 버튼 (끌 수 없음, 정상) | 상단 상태바 빨간/주황 마이크 표시 |
| 전화가 오면 | OS가 녹음 일시 중단 | OS가 녹음 일시 중단 |
| 앱으로 돌아오면 | "녹음이 일시정지됐어요" 안내 → ▶로 이어서 녹음 | 동일 |

- 백그라운드 녹음 중에는 **화면이 정상적으로 꺼집니다**(배터리 절약). 화면을 계속 켜두는 동작은 백그라운드 녹음을 끈 경우에만 작동.
- 알림 권한은 녹음 시작 시 한 번 물어봄. 거부해도 녹음은 정상 동작.
- 장시간 녹음은 배터리를 꾸준히 소모하므로(기기마다 차이 큼), 2시간 이상 강의·집회는 충전 상태 권장. 첫 실사용 전 30분 정도 화면 끈 채 테스트해 보세요.

### 4.5 Expo Go로 테스트할 때

Expo Go에서도 앱은 열리지만 **화면을 켜둔 상태로만** 녹음이 됩니다. 이때는 `src/modes.ts`의 `ENABLE_BACKGROUND_RECORDING`을 `false`로 바꾸면 화면 자동 꺼짐 방지가 켜져서 끊기지 않아요.

## 5. 모드 프리셋 요약 (`src/modes.ts`)

| 모드 | 화자분리 | 키워드 부스팅 | 정리 항목 | RAG 컬렉션 |
|---|---|---|---|---|
| 상담 | ON | 보험 용어 + 손보사명 | 고객 니즈 · 안내 내용 · 약속사항 · 후속조치 | `consult` |
| 회의 | ON | (직접 추가) | 결정사항 · 액션아이템 · 보류 안건 | `meeting` |
| 강의 | OFF | (직접 추가) | 3줄 요약 · 챕터별 정리 · 핵심 개념 · 내 질문 | `lecture` |
| 말씀 | OFF | 성경 66권 | 본문 · 핵심 메시지 · 적용점 · 묵상 질문 | `sermon` |

화자분리·키워드·정리 항목은 다음 단계(STT 연결) 때 실제로 엔진에 전달됩니다.
