## 2. 웹앱 사용법

### 처음 한 번
- **아이폰**: Safari로 주소 열기 → 아래 **공유 버튼** → **홈 화면에 추가** → 아이콘으로 실행
- **갤럭시**: Chrome으로 주소 열기 → 화면의 **설치** 버튼 (또는 메뉴 ⋮ → 앱 설치)
- **맥**: Safari 메뉴 **파일 → Dock에 추가** (또는 Chrome 주소창 오른쪽 설치 아이콘)
- 첫 녹음 때 **마이크 허용** 누르기

### 기능
| 기능 | 설명 |
|---|---|
| 4개 모드 | 상담 · 회의 · 강의 · 말씀 — 마지막 모드 기억 |
| 녹음 고지 확인 | 상담·회의·강의는 시작 전 확인 |
| 녹음 | 시작 · 일시정지 · 재개 · 종료, 타이머, 음량 파형 |
| 화면 유지 | 녹음 중 화면이 자동으로 꺼지지 않게 유지 |
| **자동 복구** | 1초마다 기기에 저장 → 앱이 강제로 꺼져도 다음 실행 때 "(복구됨)"으로 살아남 |
| 끊김 처리 | 전화 등으로 마이크가 끊기면 그때까지 녹음을 저장 |
| 목록 | 모드별 필터, 길이·용량 표시, 사용 중인 저장공간 표시 |
| 재생 | 재생바, ±15초, 배속 1~2x |
| 내보내기 | 카톡·메일·파일 앱·에어드롭으로 녹음 파일 전송 (아이폰 m4a / 갤럭시 webm) |
| 오프라인 | 한 번 열면 인터넷 없이도 실행 |

### 저장 위치
녹음은 **그 기기의 그 브라우저 안에만** 저장됩니다 (서버로 안 나감).
- 기기끼리 자동 동기화 안 됨 → 옮길 땐 **파일로 내보내기**
- 브라우저의 "방문 기록·사이트 데이터 삭제"를 하면 녹음도 지워짐 → 중요한 녹음은 내보내기로 백업
- 아이폰은 Safari와 홈 화면 앱의 저장소가 서로 다름 → **홈 화면 앱으로만** 쓰는 걸 권장

## 3. 갤럭시 설치 앱 (화면 꺼도 녹음)

1. 폰에서 저장소 **Releases** 열기 → 최신 APK 다운로드
2. "출처를 알 수 없는 앱 설치" 허용 (처음 한 번)
3. 설치 → 실행 → 마이크·알림 허용

- 녹음 중 알림창에 "녹음 중" 고정 알림이 뜸 (정상, 녹음 끝나면 사라짐)
- 화면 끄기 · 다른 앱 사용 중에도 녹음 계속
- 새 버전 APK를 설치하면 **기존 녹음 유지된 채 업데이트**됨 (같은 서명키 사용)

---

## 4. 아이폰에서 화면 끄고 녹음하려면

아이폰은 웹앱의 백그라운드 마이크를 허용하지 않습니다. 화면을 끈 채 녹음하려면 네이티브 앱이 필요하고, 이 저장소의 앱 코드는 이미 대응돼 있습니다(백그라운드 오디오 설정 포함). 필요한 것:
- **Apple 개발자 계정** (연 $99, developer.apple.com)
- 계정이 생기면 EAS Build → TestFlight로 본인·직원 아이폰에 설치 (`eas.json` 준비됨)

그전까지는 웹앱을 **화면 켜둔 채**로 쓰면 됩니다. 녹음 중엔 화면이 자동으로 꺼지지 않게 유지되며, 전원 버튼만 누르지 않으면 됩니다.

## 5. 자동 빌드·배포 구조

`main` 브랜치에 코드가 올라가면 GitHub이 알아서 처리합니다.

| 변경된 곳 | 자동 작업 | 결과 |
|---|---|---|
| `web/` | 웹앱 빌드 → GitHub Pages 게시 | 웹 주소 갱신 (약 1~2분) |
| 그 외 앱 코드 | 안드로이드 APK 빌드 → 서명 → Releases 게시 | 새 APK (약 15~25분) |

- 진행 상황: 저장소 → **Actions** 탭
- APK 서명키: 저장소 Settings → Secrets → `ANDROID_KEYSTORE_BASE64` (절대 삭제 금지 — 바뀌면 업데이트 설치 불가)

## 6. 폴더 구조

```
voice-note/
├── web/                          # ★ 웹앱 (맥·아이폰·갤럭시 공용)
│   ├── src/App.tsx               #   화면 (홈·녹음·저장·상세)
│   ├── src/useRecorder.ts        #   녹음 엔진 (마이크·파형·화면유지·1초 저장)
│   ├── src/db.ts                 #   기기 저장소 + 자동 복구
│   ├── src/modes.ts              #   4개 모드 설정
│   └── public/                   #   앱 아이콘·설치 정보·오프라인 실행
├── App.tsx, src/                 # ★ 네이티브 앱 (갤럭시 APK / 향후 아이폰)
│   └── src/modes.ts              #   4개 모드 설정 (키워드 사전 포함)
├── app.json, app.config.ts       # 앱 이름·권한·백그라운드 녹음·버전 자동 증가
├── eas.json                      # (아이폰용) EAS 빌드 설정
└── .github/workflows/
    ├── web-pages.yml             # 웹앱 자동 배포
    └── android-apk.yml           # APK 자동 빌드
```

모드를 바꾸거나 추가하려면 `web/src/modes.ts`와 `src/modes.ts`를 같이 수정하세요.
